# Dolly

Serverless end-to-end encrypted messenger. Peers talk directly over the internet; each device is the
only storage. Dependency-free: platform crypto and networking only.

- `docs/PROTOCOL.md` — wire protocol spec (v1)
- `core-swift/` — iOS/macOS core (Swift package, CryptoKit)
- `core-kotlin/` — Android/JVM core (Kotlin, JCA)
- `test-vectors/vectors.json` — shared conformance vectors, generated by the Swift core

```
cd core-swift && DOLLY_WRITE_VECTORS=1 swift run dolly-selftest   # once, to (re)generate vectors
cd core-swift && swift run dolly-selftest
cd core-kotlin && gradle test                       # JDK 17+
```
