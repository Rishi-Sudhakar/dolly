# Dolly

Serverless end-to-end encrypted messenger. Peers talk directly over the internet; each device is the
only storage. Dependency-free: platform crypto and networking only.

- `docs/PROTOCOL.md` — tickets, handshake, Double Ratchet, packet format
- `docs/TRANSPORT.md` — STUN, UDP hole punching, reliable delivery, chunking
- `core-swift/` — iOS/macOS core (Swift package, CryptoKit, POSIX sockets)
- `core-kotlin/` — Android/JVM core (Kotlin, JCA, `java.net`)
- `test-vectors/` — conformance vectors generated by the Swift core, replayed by Kotlin

```
# Swift (any toolchain, no XCTest needed)
cd core-swift && swift run dolly-selftest
cd core-swift && swift run dolly-selftest --write-vectors   # regenerate vectors (only if the wire format changed on purpose)
cd core-swift && swift run dolly-selftest --loopback        # also test two real UDP sockets
cd core-swift && swift run dolly-selftest --live-stun       # also query real STUN servers, report NAT type

# Kotlin (JDK 17+)
cd core-kotlin && gradle test
```
